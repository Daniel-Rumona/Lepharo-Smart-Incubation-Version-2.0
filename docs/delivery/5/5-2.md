## Requirements

### Primary Requirements
1. **Auto-Generation Trigger**: Implement trigger when intervention `userCompletionStatus` changes to `'confirmed'`
2. **Data Extraction**: Extract all required MOV fields from intervention and participant data
3. **MOV Creation**: Use existing `MOVCreationInput` interface to create MOV documents
4. **Firestore Integration**: Store generated MOV documents in `movDocuments` collection
5. **Error Handling**: Graceful handling of missing data or generation failures
6. **Performance**: Asynchronous generation that doesn't block intervention completion

### Technical Requirements
1. **Integration Points**: Hook into existing intervention completion workflow
2. **Data Sources**: Extract data from `interventionsDatabase`, `participants`, and `consultants` collections
3. **Validation**: Use existing `canGenerateMOV` and `validateMOVData` functions
4. **Idempotency**: Ensure MOV generation doesn't create duplicates for same intervention
5. **Logging**: Comprehensive logging for debugging and audit purposes
