## Requirements

### Primary Requirements
1. **MOVDocument Interface**: Create comprehensive TypeScript interface for MOV documents based on MOV-example.md requirements
2. **Firestore Schema**: Design efficient Firestore collection structure for `movDocuments`
3. **Data Relationships**: Establish proper linking between MOV documents and existing `interventionsDatabase` entries
4. **Multi-tenancy Support**: Ensure proper `companyCode` scoping for MOV documents
5. **Status Enumeration**: Define all possible MOV document statuses and transitions

### Technical Requirements
1. **Type Safety**: All interfaces must be strongly typed with proper TypeScript definitions
2. **Firestore Compliance**: Schema must follow Firestore best practices for indexing and querying
3. **Extensibility**: Structure should support future enhancements (digital signatures, attachments)
4. **Performance**: Design for efficient queries by participant, date ranges, and status
