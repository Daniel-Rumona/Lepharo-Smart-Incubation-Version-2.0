## Requirements

### Primary Requirements
1. **MOV List View**: Create dedicated page displaying all MOV documents with filtering and sorting
2. **Advanced Filtering**: Filter by status, intervention type, date range, facilitator, beneficiary
3. **Bulk Operations**: Ability to update status for multiple MOV documents
4. **MOV Detail Modal**: Comprehensive view showing all MOV document information
5. **Status Management**: Interface for updating MOV status (generated → signed → verified → complete)
6. **Export Capabilities**: Bulk export of MOV documents as PDF or Excel
7. **Search Functionality**: Search across MOV titles, beneficiary names, and facilitators

### Technical Requirements
1. **Routing**: Add new route `/operations/mov` for MOV management
2. **Components**: Create reusable MOV list table and detail modal components
3. **State Management**: Manage MOV data, filtering, and bulk selection states
4. **API Integration**: Utilize existing MOV service functions and add new ones as needed
5. **Performance**: Implement pagination and lazy loading for large datasets
6. **Multi-tenancy**: Ensure all operations respect `companyCode` scoping
