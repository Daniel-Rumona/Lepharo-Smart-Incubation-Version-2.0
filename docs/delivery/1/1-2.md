## Description

Create a receptionist-specific dashboard interface that provides branch-scoped inquiry management capabilities. This dashboard will serve as the main workspace for receptionists to view, manage, and track inquiries for their assigned branch, including key metrics, recent activity, and quick access to common actions.

## Requirements

### Core Dashboard Features
1. **Dashboard Overview**: Key metrics and statistics for the branch
2. **Recent Inquiries**: List of recent inquiries with quick status updates
3. **Urgent Items**: Highlighted urgent inquiries and pending follow-ups
4. **Quick Actions**: Fast access to create new inquiry and common tasks
5. **Performance Metrics**: Personal and branch-level performance indicators

### Data Display Requirements
1. **Branch Context**: All data filtered to receptionist's assigned branch
2. **Real-time Updates**: Dashboard data should refresh automatically
3. **Responsive Design**: Works well on desktop and tablet devices
4. **Loading States**: Proper loading indicators during data fetching
5. **Error Handling**: Graceful error messages and retry mechanisms

### Navigation and Layout
1. **Receptionist Menu**: Branch-specific navigation options
2. **Breadcrumbs**: Clear navigation path indication
3. **Search Functionality**: Quick search across inquiries
4. **Filter Options**: Filter inquiries by status, priority, source, etc.
5. **Bulk Actions**: Select multiple inquiries for bulk status updates

### Security and Access Control
1. **Branch-Scoped Data**: Only show data for assigned branch
2. **Role-Based UI**: Show appropriate actions based on receptionist role
3. **Data Validation**: Validate all user inputs and actions
4. **Audit Trail**: Log all actions for compliance
