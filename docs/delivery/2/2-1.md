## Requirements

### Functional Requirements
1. **Branch Collection**: Create `branches` collection with comprehensive branch information
2. **User Assignment Fields**: Add `assignedBranch` field to user documents for branch-scoped roles
3. **Assignment Audit**: Implement audit trail for branch assignment changes
4. **Data Validation**: Ensure data integrity and validation rules
5. **Migration Strategy**: Plan for existing user data migration

### Technical Requirements
1. **Firestore Schema**: Proper document structure and field types
2. **Indexing**: Efficient queries for branch and assignment operations
3. **Performance**: Optimized for read-heavy operations
4. **Security Rules**: Firestore security rules for branch data access
5. **Backward Compatibility**: Ensure existing functionality continues to work

### Data Requirements
1. **Branch Information**: Name, location, contact details, company code association
2. **Assignment Tracking**: User ID to branch ID mappings with timestamps
3. **Historical Data**: Preserve assignment history for audit purposes
4. **Validation Rules**: Constraints on assignments and branch data
5. **Company Scoping**: Ensure branches are properly scoped to companies
6. **🔴 CRITICAL SCOPING RULES**:
   - **CENTER COORDINATORS (projectadmin)** = **BRANCH-scoped** (NOT department)
   - **RECEPTIONISTS** = **BRANCH-scoped** (NOT department) 
   - **OPERATIONS** = **DEPARTMENT-scoped** (NOT branch)
   - **assignedBranch** and **department** are **MUTUALLY EXCLUSIVE**
